GoalStatus
GoalStatus is one goal and its lifecycle. Returned (embedded in Status) by every method that starts, suspends, resumes, or cancels motion, and embedded in Status from GetNavigationStatus. Only the latest goal is kept. SUCCEEDED, FAILED, and CANCELED are terminal.

Route
Route is an ordered list of waypoints. A location can appear in more than one route, and more than once in the same route.
RouteProgress
Status
Status is the robot navigation state returned by GetNavigationStatus and by methods that start, suspend, or resume motion. The robot is idle when goal is unset or goal.state is terminal. It is moving when goal.state == GOAL_STATE_ACTIVE. Methods that start motion fail while localized is false.

Waypoint
Waypoint is a route stop: either the name of a saved Location or an inline Position.
WaypointList
WaypointList is a wrapper so callers can distinguish an unset list from an empty one. Proto3 repeated fields have no presence.
Zone
Zone is a named region on the active map. Geometry is a Struct following the Geometry shapes described in the Navigation API (circle, box, or polygon). Units follow the map type: millimeters on local maps, meters for GPS radii and sizes.
